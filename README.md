# 无尽心城 · INNERVERSE

一座由热爱搭建的可交互精神城：四重梦境、32 个主题房间、可环绕的悬浮建筑、九种互动机关、收藏和记忆手帐。

## 本地体验

使用浏览器打开 `index.html`，或在当前目录运行 `python -m http.server 4318`，访问 `http://localhost:4318`。

## GitHub Pages

这是无构建依赖的静态网站。GitHub 仓库的 Settings → Pages 中，选择 Deploy from a branch，发布分支 `main`，目录 `/ (root)`。

## 操作

拖动旋转，滚轮或双指缩放；点击建筑标签进入房间。数字 1—4 切换梦境，`/` 或 `Ctrl / Command + K` 搜索，`Esc` 返回。也可从梦境地图或随心漂流进入。

完成房间机关收集碎片，在四重梦境各收集至少一枚后，便可唤醒心核。

## 进度与声音

收藏、碎片和留言仅保存在当前浏览器，不上传服务器。可在记忆手帐中导出文本副本。不同网址和浏览器的记录独立。

右上角 ♫ 开启原创合成环境音；不包含商业歌曲音源，没有接入 AI 服务。

## 内容与实现

全部房间文字、几何建筑、主题插画及机关为原创致敬。作品、人物和品牌名称用于标识兴趣主题，不代表官方授权、官方观点或人物原话。

使用原生 HTML / CSS / JavaScript 与自制 WebGL 渲染器，无外部依赖。

- `data.js`：房间与梦境内容
- `world.js`：程序化建筑与空间交互
- `app.js`：房间机关、收藏、手帐及进度
- `style.css`：桌面与移动端布局
